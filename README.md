# Ruby 포트폴리오 사이트

인스타 2계정은 자동으로, X는 구글 시트에 링크를 넣으면 1시간마다 사이트에 반영됩니다.

## 채널 (계정별 분리)
- 맨 위에서 **Liora Solveil / Milo&Luna**를 고르면 이름, 팔로워 수, 작품·시리즈·광고 탭이 모두 그 계정 기준으로 바뀝니다.
- 주소로도 바로 들어갈 수 있습니다. 예: `사이트주소/#/milo`, `사이트주소/#/liora/series/UNCAGED`
- **계정 추가**: `config.json`의 `channels`에 한 덩어리(이름, 인스타·페이스북·X 정보, 시리즈 키워드)를 복사해 추가하고, 인스타 토큰 Secret을 하나 더 넣으면 됩니다. 채널 버튼은 자동으로 생깁니다.
- X 링크는 글쓴이 계정(@LioraSolveil 등)을 보고 채널을 자동으로 찾습니다. 다른 채널에 넣고 싶으면 시트 채널 칸에 `liora`나 `milo`를 적으세요.

## 화면
- **작품** (첫 화면): 광고를 뺀 전체 영상을 조회수 높은 순으로 보여 줍니다. 1~3위에는 순위 숫자가 붙습니다.
- **시리즈**: 시리즈별 표지가 나오고, 누르면 회차 순으로 보여 줍니다. 주소로 바로 들어갈 수도 있습니다. 예: `사이트주소/#/series/UNCAGED`
- **광고 작업**: 광고로 분류된 영상만 브랜드명과 함께 보여 줍니다.
- 영상을 누르면 전체 화면 세로 플레이어가 열립니다. 위아래로 밀거나 ↑↓ 키를 누르면 이전·다음 영상으로 넘어가고, Esc나 뒤로 가기로 닫힙니다.

## 분류 규칙 (위에 있는 규칙이 우선)
1. **구글 시트에 적은 값**: 시리즈 칸에 이름을 적으면 그 시리즈로 들어갑니다. 처음 쓰는 이름이면 탭이 새로 생깁니다.
2. **제목 키워드**: 각 채널의 `seriesKeywords` 목록과 맞으면 그 시리즈로 들어갑니다.
3. **자동 감지**: 제목이 `새이름 Ep.01` 형태면 `새이름` 시리즈가 자동으로 만들어집니다.
- **광고**: 캡션에 `#광고`, `#유료광고`, `#협찬`, `#ad` 등이 있거나, 시트의 광고 칸에 O를 적으면 광고로 분류됩니다. 브랜드 칸을 비워 두면 글에서 처음 언급한 계정(예: `@polloai_kr`)을 브랜드로 표시합니다.
- **회차**: 제목의 `2기 3화`, `Ep.03` 같은 표기를 읽어서 시리즈 안에서 기수 → 회차 순으로 정렬합니다.
- **X 조회수**: X는 무료로는 조회수를 주지 않습니다. 작품 탭이 조회수순이니 시트 조회수 칸에 직접 적어 주세요. 비어 있으면 맨 뒤로 갑니다.
- **화면 비율**: 가로 영상이 많은 목록(X 시리즈, 광고)은 16:9 카드로, 나머지는 9:16 카드로 보여 줍니다.

## 구글 시트 형식 (첫 줄은 이 제목 그대로)
| 링크 | 채널 | 시리즈 | 광고 | 브랜드 | 제목 | 조회수 | 숨김 |
|---|---|---|---|---|---|---|---|
| https://x.com/.../status/123 | | 해리, 내 뒤에 있어 | | | | 85000 | |
| https://x.com/.../status/456 | | | O | 브랜드명 | 런칭 필름 | 340000 | |
| https://www.instagram.com/reel/ABC/ | liora | UNCAGED | | | UNCAGED Ep.02 | | |

채널 칸은 비워 두면 자동으로 정해집니다(X는 글쓴이 계정, 인스타는 자동 수집된 계정).

- 링크 칸에는 **X 링크와 인스타 링크를 모두** 넣을 수 있습니다. 인스타 링크를 넣으면 자동 분류 결과를 덮어씁니다. 제목 없이 올린 UNCAGED 2화 같은 경우에 쓰면 됩니다.
- 조회수 칸은 비워 두면 자동으로 가져온 값을 씁니다. X 조회수를 자동으로 못 가져오면 직접 적으세요.
- 숨김 칸에 O를 적으면 그 영상은 사이트에 나오지 않습니다.
- 시트 공유 설정: 파일 → 공유 → 웹에 게시 → CSV를 선택하고, 나온 주소를 `SHEET_CSV_URL`에 넣습니다.

## 연결할 때 필요한 것 (GitHub 저장소 → Settings → Secrets → Actions)
| 이름 | 내용 |
|---|---|
| `IG_TOKEN_MAIN` | 메인 인스타 장기 토큰 (Meta 개발자 앱 → Instagram API → 토큰 생성) |
| `IG_TOKEN_MILO` | milo_lunaworld 장기 토큰 |
| `FB_PAGE_TOKEN_1`, `FB_PAGE_TOKEN_2` | 페이스북 페이지 2개의 토큰 (팔로워 수용, 선택) |
| `X_BEARER_TOKEN` | 선택. 없으면 `config.json`의 `x.followersManual`에 적은 숫자를 씁니다 |
| `SHEET_CSV_URL` | 위에서 받은 구글 시트 CSV 주소 |
| `GH_PAT` | 인스타 토큰 자동 갱신용 GitHub 개인 토큰 (Secrets 쓰기 권한) |

설정을 마치고 GitHub Pages의 소스를 "GitHub Actions"로 바꾸면, 매시 7분에 자동으로 갱신됩니다.
